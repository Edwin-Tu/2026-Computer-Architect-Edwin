# instructions/

本目錄為學生可選的 19 條指令,每條一個子目錄(以序號加指令名稱命名,例如 `01_ABS`),依 HOMEWORK.md 第六節的語意規格建立目錄結構。

| 類別 | 指令 |
|---|---|
| 基礎運算 | `01_ABS`、`MIN`（本組正式入口）、`03_AVG`、`04_CLAMP`、`05_ABSDIFF`、`06_THRESHOLD`、`07_MAXPIX` |
| AI / 視覺 | `08_ReLU6`、`09_Leaky_ReLU`、`10_CLIP`、`11_POPCOUNT`、`12_SAD` |
| 網路 | `13_NETMASK`、`14_CSUM16` |
| 密碼學 | `15_ROTL` |
| DSP | `16_ADDSAT`、`17_BITREV` |
| 字串 | `18_FINDZERO` |
| 算術 | `19_CLZ` |

示範題 `MAC`(見 `mac_demo/`)與 `TOP2_4` 不列入學生目錄。

## 本組 MIN 正式入口

- [MIN 語意規格](MIN/README.md)：唯一正式規格。
- [實作、測資與證據](../src/README.md)。
- [報告索引](../report/README.md)：唯一正式 CP3 報告入口。
